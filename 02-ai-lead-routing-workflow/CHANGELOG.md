# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-09-08

### Added

- Protected lead-intake webhook with consent and input validation.
- Pre-AI idempotency lookup.
- Schema-bound AI signal extraction through n8n's Information Extractor.
- Deterministic scoring policy version 1.0.0.
- Native HubSpot contact create/update.
- Hot, warm, cold, and needs-review routing.
- Gmail drafts, Telegram notifications, and Google Sheets audit trail.
- CRM failure preservation and separate Error Workflow.
- Synthetic fixtures, acceptance tests, security notes, and CI validation.
- Deterministic generator for demo requests and expected AI extraction examples.
- Neutral fixture filenames and idempotency keys to prevent label leakage into future model inputs.

# Security Policy

## Supported Version

Only the latest tagged version receives security fixes.

## Reporting a Vulnerability

Do not open a public issue containing credentials, personal data, or exploit details. Contact the repository owner privately through the security-reporting method configured on the GitHub profile. Include the affected workflow, impact, reproduction steps using synthetic data, and a suggested mitigation if known.

## Deployment Responsibility

This repository is a reference implementation. Operators are responsible for authentication, rate limiting, credential scope, data retention, monitoring, provider agreements, concurrency testing, and applicable privacy law before processing real lead data.

# Security Policy

## Reporting

Do not open a public issue containing credentials, private webhook URLs, personal data, or real invoices. Report security-sensitive findings privately to the repository owner through the contact method listed on their GitHub profile.

## Supported Version

Only the latest tagged release is maintained.

## Scope

This repository is a portfolio-grade MVP and has not undergone a professional security or compliance audit. Review `docs/threat-model.md` before using it outside a test environment.
